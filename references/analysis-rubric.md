# Visual Analysis Rubric

生成新风格或替换主体前使用本表。多图分别观察，再提取交集。

| 模块 | 必查内容 | 参数表达 |
|---|---|---|
| 画布 | 比例、方向、安全边距、用途 | 宽高比、边距占短边百分比 |
| 主体 | 类型、占比、位置、角度、姿态、裁切 | 包围盒占画布比例、角度区间 |
| 辅助元素 | 数量、占比、与主体关系 | 画布占比、密度、前中后景 |
| 留白 | 总量、集中方向、是否承载文字 | 画布百分比和区域 |
| 构图 | 居中、左右、上下、对角线、非对称 | 网格、视觉动线、重心 |
| 色彩 | 主辅色、饱和度、明度、温度、对比 | 颜色角色、近似 HEX、面积区间 |
| 光影 | 光型、方向、软硬、明暗比、投影 | 类型、方向、强度关系 |
| 文字 | 字体类别、字重、大小层级、排列方向 | 标题/副文/标签相对比例 |
| 材质 | 纸张、颗粒、笔触、涂料、织物、金属 | 表面、粗糙度、反射、边缘 |
| 情绪 | 克制、可爱、速度、神秘、奢华等 | 3–6 个稳定关键词 |

## 身份与风格分离

- `identity_reference` 决定角色五官、产品结构、logo、包装和识别锚点。
- `style_reference` 决定构图、色彩、笔触、材质、字体和气质。
- `edit_target` 决定必须保留的画布与现有元素。
- 不平均混合不同角色：明确每张图负责什么。

## 成年化比例检查

“长大”先通过以下结构检查，随后才允许增加时尚感：

1. 总体为约 `6.5–7` 头身；IP 头部可略大，但不得把身体压成幼儿比例。
2. 胯部接近头顶至鞋底的中点。
3. 胯至鞋底约为总高的 `47%–50%`；普通成年化不得写 `53%–56%` 的超模长腿。
4. 膝盖处于胯和脚踝之间的自然位置；大腿与小腿长度接近但不机械相等。
5. 手臂自然下垂时，手腕接近胯部，指尖在大腿中段附近。
6. 鞋长与脚踝、腿宽协调；厚底鞋不能成为延长身高的工具。
7. 45°姿势要看见肩线、胸腔、骨盆与前后脚的旋转关系，不能只把双腿拉成对角线。

任一项明显失败，就将提示词改成“重建骨架比例”，而不是“把腿缩短一点”。后者容易保留错误骨架。

## 质量检查

- 身份：是否仍是一眼可识别的同一角色或产品？
- 比例：主体是否完整、协调、没有随意拉伸？
- 构图：主体、文字、留白是否保持系列规则？
- 色彩：主色面积与强调色频率是否稳定？
- 光影：光源和投影是否一致？
- 文字：品牌拼写是否准确，是否出现乱码或重复？
- 材质：是否出现塑料感、噪点、碎纹、脏色或过度锐化？
- 边界：手指、鞋、鹿角、产品边缘是否完整？
